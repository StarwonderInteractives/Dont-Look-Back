# 🕯️ DON’T LOOK BACK

A **text-based psychological horror game** inspired by Telltale-style storytelling.  
Choices affect sanity, episodes branch, and the corridor remembers.

## ✨ Features

- Episode select menu with 4 chapters  
- Sanity system with UI color shift  
- Cinematic episode title cards  
- Endings overlay with name and progress counter  
- Branching narrative with multiple endings  
- Warix horror font  

---

## 🕹️ How to Play

1. Open the game link (or `index.html` locally)  
2. Select an episode from the menu  
3. Read the story and make choices  
4. Watch your sanity meter  
5. Reach an ending; the game auto-returns to the episode menu
